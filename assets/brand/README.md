# Botiny brand assets

Canonical mark: **v3 V1 — ink head, sprout** (recommended in the Botiny brand kit). The same artwork is used by the later marketing site (`site-v4`) and the Firebase page in [`website/`](../../website/).

Copied from the brand kit on 23 November 2026. SVGs are the source; PNGs are rasterised sizes for READMEs, tabs and social previews.

## Files

| File | Use |
|---|---|
| `logo.svg` / `logo.png` (1400×480) | Wordmark on a light background |
| `logo-on-dark.svg` / `logo-on-dark.png` | Wordmark on a dark background |
| `mark.svg` / `mark.png` (512×512) | Icon only |
| `mark-512.png`, `mark-256.png`, `mark-128.png`, `mark-64.png`, `mark-32.png` | Icon sizes (and matching `mark-on-dark-*`) |
| `favicon.svg`, `favicon.ico` | Tab icon |

## Palette

| Name | Hex | Role |
|---|---|---|
| Ink | `#111418` | Wordmark, robot head |
| Blue | `#2F6BFF` | Ring quadrant |
| Red | `#FF4D3D` | Ring quadrant |
| Yellow | `#FFC83D` | Ring quadrant, left leaf |
| Green | `#22B573` | Ring quadrant, right leaf |
| Soft | `#F5F6F8` | Light surfaces |
| Slate | `#4A5160` | Supporting text |

Typography: **Space Grotesk** 700 for the wordmark and headings, **Inter** for body, **JetBrains Mono** for code and 402 snippets.

The earlier Concept A “Sprout Bot” (ink `#0E1412`, sprout `#2BD67B`, paper `#F4F1E8`) is a previous exploration and is not used in this repo.
